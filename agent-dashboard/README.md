# Orbit – AI Agent Dashboard

**Topic:** AI Agents (Agent Dashboard, Status Monitoring, Task Queue, Activity Log, Human-in-the-loop Approval)

## Research
1. **What it is:** A control room where people watch what AI agents are doing and step in when needed.
2. **Where it is used:** AI automation tools, customer support platforms, workflow builders.
3. **Why it matters:** Agents act on their own, so people need clear status, history, and a way to approve risky actions.
4. **Patterns observed:** live status chips, progress bars, streaming activity feeds, approval cards, on/off switches.
5. **What this version adds:** a bold motion-design look (inspired by indianschoolofmotion.com: royal blue and yellow, Inter font, big animated headline, scrolling ticker), live chart, animated numbers, working approve/reject, pause/resume agents, and no libraries.

## Run it
Open `index.html` in any modern browser. No install needed.

## Files
`index.html` (structure), `style.css` (design, responsive), `script.js` (live data and interactions)
