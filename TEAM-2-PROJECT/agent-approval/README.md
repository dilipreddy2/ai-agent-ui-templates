# Orbit – Agent Approval Interface

**Topic:** AI Agents → Agent Approval Interface (Human-in-the-loop)

## Research
1. **What it is:** A page where a person reviews actions an AI agent wants to take, and approves or rejects each one before it happens.
2. **Where it is used:** AI assistants that send emails, move money, or change data; automation and security tools.
3. **Why it matters:** Agents can make mistakes, so risky actions need a human check. This pattern builds trust.
4. **Patterns observed:** risk labels, a short "what will happen" list, a preview of the action, confidence score, expiry timer, approve and reject buttons, keyboard shortcuts.
5. **What this version adds:** a countdown on every request, a reason box when rejecting, A and R keyboard shortcuts, an auto-approve switch for low-risk requests, new requests arriving live, blue, yellow and white design, custom cursor, and no libraries.

## Run it
Open `index.html` in any modern browser.
