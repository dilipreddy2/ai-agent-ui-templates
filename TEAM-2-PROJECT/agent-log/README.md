# Orbit – Agent Activity Log

**Topic:** AI Agents → Agent Activity Log

## Research
1. **What it is:** A time-ordered feed of everything AI agents have done: tasks, warnings, and errors.
2. **Where it is used:** Automation platforms, audit tools, DevOps and support dashboards.
3. **Why it matters:** Agents act on their own, so people need a clear record to trust them and to find out what went wrong.
4. **Patterns observed:** search, type filters with counts, time ranges, status dots, relative times, expandable details, export.
5. **What this version adds:** a live feed where new events flash in, click-to-expand details, filters that work together, CSV export, blue, yellow and white design, custom cursor, and no libraries.

## Run it
Open `index.html` in any modern browser.
