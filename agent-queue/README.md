# Orbit – Agent Task Queue

**Topic:** AI Agents → Agent Task Queue

## Research
1. **What it is:** A list of the work waiting for AI agents, with priority, progress, and controls.
2. **Where it is used:** Automation platforms, support tools, job runners.
3. **Why it matters:** Agents can only do a few things at once, so people need to see and steer what comes next.
4. **Patterns observed:** priority badges, progress bars, status chips, move up/down, pause and cancel, filters.
5. **What this version adds:** a working simulation (2 tasks run at once, the next one starts when one finishes), add-task form, reordering, filters, blue, yellow and white design, custom cursor, and no libraries.

## Run it
Open `index.html` in any modern browser.
