# Orbit – AI Agent List

**Topic:** AI Agents → Agent List

## Research
1. **What it is:** A page that shows every AI agent in one place, with its status and key numbers.
2. **Where it is used:** AI automation platforms, support tools, workflow builders.
3. **Why it matters:** Teams run many agents at once and need to find, compare, and control them quickly.
4. **Patterns observed:** search bar, status filter chips, sort menu, grid/list toggle, status badges, small trend charts, on/off switches.
5. **What this version adds:** blue, yellow and white design, animated card entrance, live filtering and sorting, custom cursor, and no libraries.

## Run it
Open `index.html` in any modern browser.
