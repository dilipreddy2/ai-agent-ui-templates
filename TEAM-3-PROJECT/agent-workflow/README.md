# Orbit – Automation Workflow Builder

**Topic:** AI Agents → Automation Workflow Builder / Trigger & Action Workflow

## Research
1. **What it is:** A visual canvas where you connect blocks (a trigger that starts the flow, then actions) to automate work without writing code.
2. **Where it is used:** Tools like Zapier, n8n, Make, and AI agent platforms.
3. **Why it matters:** Anyone can design what an agent should do, step by step, and see the whole flow at once.
4. **Patterns observed:** a block palette, drag and drop onto a canvas, curved connection lines, input and output dots, a settings panel, a test run with a log.
5. **What this version adds:** drag blocks from the palette or click to add, move blocks freely, connect with two clicks, click a line to remove it, rename or delete blocks, a "Run flow" test that lights up each block and animates the lines, a run log, blue, yellow and white design, custom cursor, and no libraries.

## Run it
Open `index.html` in any modern browser.
