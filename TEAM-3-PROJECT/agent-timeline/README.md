# Orbit – Agent Execution Timeline

**Topic:** AI Agents → Agent Execution Timeline (with Execution History details)

**Colors:** a different palette from the other UIs: deep green, coral, and cream.

## Research
1. **What it is:** A view of one AI agent run, showing every step in order, how long each took, and what went in and out.
2. **Where it is used:** AI observability tools (trace views), debugging tools, and workflow platforms.
3. **Why it matters:** When an agent gives a wrong or slow answer, people need to see exactly which step caused it.
4. **Patterns observed:** a waterfall chart of step durations, a vertical step list with status dots, colored step types, a playhead, expandable input and output, retry notes.
5. **What this version adds:** a replay with a moving playhead, 1x/2x/4x speed, a scrubber to jump to any moment, steps that light up as they run, click-to-expand details, a human-approval step, custom cursor, and no libraries.

## Run it
Open `index.html` in any modern browser.
