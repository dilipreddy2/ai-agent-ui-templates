# Orbit – Agent Permissions

**Topic:** AI Agents → Agent Permissions

**Colors:** a third palette, different from the other UIs: deep violet, lime, and lavender-white.

## Research
1. **What it is:** A control panel where a person decides what each AI agent is allowed to do: read data, send emails, spend money, and more.
2. **Where it is used:** AI agent platforms, admin consoles, security and access-control tools.
3. **Why it matters:** Agents act on their own, so limits protect people and companies. Giving every agent full access is risky.
4. **Patterns observed:** a permission matrix (rows are actions, columns are agents), risk labels, three levels (deny, ask first, allow), role presets, and a save bar for unsaved changes.
5. **What this version adds:** an "Ask first" level that connects to the human approval idea, a live risk meter for each agent, one-click presets, search, a warning when a high-risk action is allowed, an unsaved-changes bar with Save and Discard, custom cursor, and no libraries.

## Run it
Open `index.html` in any modern browser.
